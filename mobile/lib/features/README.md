# Features

Cada módulo de GISAM vive separado para evitar convertir `main.dart` en un pulpo.

- home: árbol, XP y misiones
- friends: relaciones directas y QR
- music: integración musical
- community: espacio social
- chatbot: conversación con el backend
- game: gamificación
- store: recompensas
- settings: configuración
